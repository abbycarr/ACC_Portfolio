# ACC_Portfolio

A GitHub-hosted website displaying my technical, creative, and instructional work. 

View demo at: [https://abbycarr.github.io/ACC_Portfolio/](https://abbycarr.github.io/ACC_Portfolio/)

## Technologies

Built with
- [Alpine.js](https://alpinejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)

## Getting Started

No dependencies. 

1. Clone Repository
git clone [https://abbycarr.github.io/ACC_Portfolio/](https://abbycarr.github.io/ACC_Portfolio/)

2. To localhost the site
Example Method:    
   requiring Node.js ([download instructions here](https://nodejs.org/en/download)) 

   cd ACC_Portfolio
   npx serve src

### Usage

This site includes links to contact and connect. A user may read about me, and navigate through projects to read more detail.
